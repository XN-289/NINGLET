# 情绪回报模式参考

## 核心原则

读者阅读的驱动力 = 情绪债务的积累与释放

每一次读者感到愤怒、委屈、担忧，就是一笔情绪债务。
每一次爽感、解气、感动，就是一次情绪回收。
好的网文 = 精确管理情绪账户。

---

## 主要情绪债务类型

### 愤怒型

**积累方式**：反角的欺压、不公正待遇、无辜者受害
**回收方式**：打脸、逆袭、公开揭露
**积累/回收比例**：积累1次，回收1次或1.5倍
**注意**：积累太多而不回收会让读者愤怒转移到作者

---

### 担忧型

**积累方式**：主角陷入危机、重要人物受到威胁
**回收方式**：主角脱险、危机解除
**积累/回收比例**：短时间内必须回收（最多5章）
**注意**：长期担忧而不解决会让读者疲劳

---

### 期待型

**积累方式**：埋下悬念、预告未来事件
**回收方式**：悬念揭露、预告事件兑现
**积累/回收比例**：中长期债务，最多30章
**注意**：忘记回收是对读者的背叛

---

### 委屈型

**积累方式**：主角被误解、遭受不公
**回收方式**：误解解开、得到认可
**积累/回收比例**：10章内必须有开始缓解的信号
**注意**：主角长期委屈会让读者难受而弃书

---

## 爽点类型与节奏

### 小爽点（每2-3章）

- 战斗小胜利
- 一句解气的反击台词
- 小人物的小失败
- 主角获得一个小资源/信息

### 中爽点（每8-10章）

- 打脸场景
- 主角在众人面前的成功展示
- 关系的重要推进
- 敌人的中等挫败

### 大爽点（每30-40章）

- 卷级高潮
- 重大身份揭露
- 主角达到新阶段的巅峰
- 长期压在心头的仇恨或误解得到解决

---

## 情绪回收的质量标准

### 优质回收

- 时机恰当（不过早，不过晚）
- 方式出乎意料（不是读者预测到的套路）
- 有叠加效应（一个回收同时解决多个债务）
- 有余韵（回收后读者还想想）

### 劣质回收

- 时机太慢（读者已经不在乎了）
- 方式太简单（主角轻松就赢了，没有挣扎）
- 纯功能性（只是完成了任务，没有情感共鸣）
- 有遗漏（解决了一件事但忘了另一件事）

---

## 情绪曲线设计表

### 爽文标准曲线（每30章为一个完整周期）

```
第1-5章：  [建立]  基准情绪，建立新情况
第6-10章： [积累]  小愤怒积累，第7章小爽点
第11-15章：[压迫]  中等压力，期待感最高
第16-20章：[峰值]  中型爽点爆发（第18章左右）
第21-25章：[余波]  胜利后的调整，新威胁显现
第26-29章：[蓄力]  为大爽点做铺垫
第30章：   [大爽点] 本周期最大回收
```

### 悬疑标准曲线

```
好奇建立 → 线索积累（每章一条） → 误导高峰 → 假答案 → 更大迷惑 → 真相揭露
```

### 言情标准曲线

```
初遇张力 → 靠近 → 误解 → 更远 → 更大危机 → 和解 → 感情确认 → HE
```
