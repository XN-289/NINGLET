# 节奏模式参考

## 标准网文节奏曲线

### 单章节奏结构（2000字标准章）

```
[开头200字] 快速进入状态 → 不做背景介绍，直接进事件
[中间1400字] 场景展开 → 冲突升级 → 一次以上的转折
[结尾400字] 节奏加快 → 钩子引出 → 最后一句留悬念
```

### 五章小单元结构（约1万字）

```
第1章：建立场景/冲突 ——→ 紧张/期待
第2章：冲突升级 ——→ 压力增加
第3章：顶峰/近乎失败 ——→ 最大张力
第4章：转折爆发 ——→ 爽感释放（小爽点）
第5章：余震+新威胁 ——→ 新一轮期待
```

### 十章中单元结构（约2万字）

```
第1-3章：  新情况建立（新威胁/新机遇/新关系）
第4-6章：  深化与升级（主要冲突展开）
第7章：    中点危机（最糟糕的时刻）
第8-9章：  主角找到突破口
第10章：   中等爽点爆发 + 下一阶段预告
```

### 三十章大单元结构（约6万字，约半卷）

```
第1-8章：  新阶段建立（新舞台/新对手）
第9-15章： 竞争与磨砺
第16章：   小高潮
第17-22章：冲突扩大，暗流涌动
第23-27章：走向摊牌
第28-29章：大爽点爆发
第30章：   收束+为下30章埋钩子
```

## 情绪曲线设计

### 爽文（都市重生/玄幻升级）

```
愤怒积累 → 期待 → 短暂绝望 → 反转爆发 → 爽感峰值 → 余韵 → 新威胁（重置期待）
```

### 悬疑文

```
好奇建立 → 线索积累 → 误导迷惑 → 错误假设 → 真相揭露 → 震惊 → 情感满足
```

### 言情文

```
初遇张力 → 误解/障碍 → 靠近 → 退缩 → 更大的误解 → 和解 → 感情确认
```

### 无限流

```
死亡压力建立 → 谜题探索 → 错误假设 → 危机升级 → 规则发现 → 险中求生 → 通关释然
```

## 水章诊断标准

一章属于水章（需要大改）如果满足以下任意3条：

- [ ] 没有任何人物状态发生变化
- [ ] 没有新信息揭露或承诺开启
- [ ] 没有任何冲突或张力
- [ ] 主要内容是回忆、说明或重复已知信息
- [ ] 章末没有任何前向驱动
- [ ] 字数正常但读后记不住任何内容

## 节奏急救方案

### 感觉节奏太慢？

1. 检查是否连续3章以上没有爽点
2. 找出当前最长的纯说明段落，删减50%
3. 给最近一章的主要场景加入一个意外事件
4. 把下一个预计的中型爽点提前2章

### 感觉节奏太快（读者跟不上）？

1. 检查是否有情感落地场景（让读者喘口气）
2. 加入一个角色关系场景（对话/互动）
3. 把下一个悬念从"揭露"改为"更深的谜团"
4. 增加主角的内心反应（不是独白，是行为化的情绪）
