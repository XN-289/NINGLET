# Anti-AI Narrative Style Module

Use this module whenever drafting or revising chapter prose.

## Core Principle

Write scenes, not summaries.

The final output must read like a finished novel chapter, not an outline, review, synopsis, essay, commentary, or thematic explanation.

The reader should experience events unfolding in real time through action, dialogue, objects, space, silence, interruption, and conflict.

If the draft reads like a synopsis, essay, commentary, or chapter summary, it has failed. Rewrite it as a scene.

## Narrative Execution Rule

Write the story as something happening now.

Every chapter must be rendered through:

- concrete action
- dialogue
- sensory detail
- spatial movement
- objects
- interruptions
- mistakes
- silence
- body reactions
- character behavior

Do not explain what the scene means.
Do not summarize emotional states.
Do not describe the plot as an outline.
Do not expose author commentary.

Avoid sentences such as:

- "这意味着……"
- "他终于明白……"
- "真正的矛盾是……"
- "这不仅是……更是……"
- "从这一刻起……"
- "一切都变了。"

## Show-Don't-Tell Requirement

At least 80% of each chapter must be dramatized through:

- action
- dialogue
- physical behavior
- object interaction
- setting detail
- sensory information
- interruption
- conflict
- visible choice

At most 20% may be exposition or summary.

Every abstract sentence should be tested:

```text
Can this be turned into an action, object, gesture, spatial movement, sensory detail, or line of dialogue?
```

If yes, rewrite it.

Bad:

```text
她感到被背叛。
```

Good:

```text
她把那封信对折了两次，指甲压在旧折痕上，最后没看最后一行，直接撕开。
```

## AI-Style Ban List

Avoid these narrative patterns:

1. "这不仅是……更是……"
2. "从这一刻起……"
3. "他终于意识到……"
4. "她内心深处知道……"
5. "真正的问题在于……"
6. "这象征着……"
7. "这代表了……"
8. "某种意义上……"
9. "他不知道的是……"
10. "一切都变了。"
11. "这标志着……"
12. "命运的齿轮……"
13. "故事由此展开。"

Avoid direct abstract emotion labels when a visible behavior can carry them:

- 愤怒
- 悲伤
- 震惊
- 感动
- 孤独
- 绝望
- 迷茫
- 坚定
- 疲惫
- 痛苦
- 紧张
- 不安

Replace labels with:

- behavior
- voice
- silence
- errors
- repeated gestures
- object interaction
- unfinished sentences
- rhythm changes

## Scene Beat Workflow

Before writing a chapter, internally design a scene-beat plan. Do not output this plan unless the user asks.

1. Opening image:
   What concrete object, sound, gesture, or location opens the chapter?

2. Immediate tension:
   What is physically happening now?

3. Character objective:
   What does the viewpoint character want in this scene?

4. Obstruction:
   Who or what blocks them?

5. Escalation:
   What changes halfway through the scene?

6. Concrete turning point:
   What action, line of dialogue, discovery, or object changes the situation?

7. Ending image:
   End with an unresolved image, action, silence, consequence, or decision.
   Do not end with a moral summary.

Then write continuous novel prose.

## Dialogue Rules

Dialogue should not explain the plot directly.

Good dialogue contains:

- evasion
- interruption
- misunderstanding
- subtext
- unequal knowledge
- unfinished sentences
- ordinary words carrying hidden pressure

Avoid dialogue that sounds like:

- exposition
- author explanation
- theme statement
- character biography
- briefing document

## Hidden Logic vs Visible Text

The model may reason about themes, arcs, and character psychology internally.

The final chapter must not expose this reasoning directly.

Theme must appear as:

- repeated objects
- changed behavior
- dialogue subtext
- scene contrast
- consequences

Character psychology must appear as:

- hesitation
- avoidance
- wrong choices
- repeated gestures
- unfinished sentences
- changes in rhythm

## Ending Rule

End each scene or chapter with one of:

- an unresolved action
- a physical image
- a changed object
- a silence
- a decision
- a line of dialogue with subtext
- a consequence arriving

Do not end with:

- "一切都变了。"
- "他终于明白……"
- "这只是开始。"
- "他们的命运已经注定。"
- any abstract summary of the theme

## Scene Density Check

After drafting, check:

- Does the first paragraph contain a concrete image or action?
- Is there dialogue within the first 500 Chinese characters?
- Does every 800-1000 Chinese characters contain a visible event?
- Are abstract explanations replaced by behavior?
- Does the chapter end with an image/action/dialogue rather than a summary?
- Are there at least 3 concrete objects, body details, or sensory details?
- Does every main character reveal personality through action, not author explanation?

If more than 2 checks fail, revise before final output.

## Revision Pass

After drafting, perform an internal anti-AI revision pass:

1. Remove summary paragraphs.
2. Replace abstract emotion with visible behavior.
3. Cut theme explanation.
4. Add concrete objects and sensory details.
5. Break long explanatory paragraphs with action or dialogue.
6. Make the ending image-based instead of conclusion-based.
7. Ensure character personality appears through choices, not labels.

Only output the revised chapter.
