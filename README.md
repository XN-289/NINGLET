## 🎯 为什么做

AI 写小说，快是真快，假也是真假。

> "心中一凛" · "眼中闪过一丝XX" · "嘴角勾起一抹XX"
> 排比三连 · 段尾抒情 · 形容词堆砌 · 升华总结

这些是 **AI 写作的指纹**。读者扫一眼就知道是机器写的——不是因为写得不好，而是因为**写得太像了**。所有 AI 产出的文本都有一种共同的"正确感"，像流水线上的产品：光滑、均匀、没有毛刺。

但人写的东西不是这样的。人写的有偏好、有坏习惯、有突然的灵感和明显的缺陷。

**好的小说不是完美的，是有个性的。**

NINGLET 的目标就这一件事：

## 🕵️ 反 AI 味引擎

这是 NINGLET 的核心。不是调一个 prompt 就完事——是一整套从生成到后处理的流水线。

### AI 味从哪来？10 个维度的指纹

| 维度 | 典型症状 | |
|:---:|:---|:---:|
| 🔴 禁用词 | "心中一凛""眼中闪过一丝""嘴角勾起一抹" | 最致命 |
| 🟠 句式 | 排比三连、段尾抒情总结、对仗工整 | |
| 🟠 形容词 | 堆砌、空洞、不落地 | |
| 🟡 节奏 | 均匀推进，无快慢张弛 | |
| 🟡 情绪 | 隔靴搔痒，不敢写烈情绪 | |
| 🟡 对话 | 每句都完整、都文明、都有信息量 | |
| 🟢 细节 | 场景描写像布景，不像有人住过 | |
| 🟢 转折 | "然而""但是"机械过渡 | |
| 🟢 结尾 | 升华总结，强行正能量 | |
| 🟢 结构 | 三段式骨架外露 | |

### 两个流派，短篇只用一个

| 流派 | 用在哪 | 怎么做 |
|:---:|:---|:---|
| 🔥 **情绪烈度派** | **短篇** | 直白烈情绪，情绪词后必须接此刻场景特有的具体动作/物件 |
| 🌫️ 克制留白派 | 长篇 | Show Don't Tell，靠动作和细节暗示 |

> 短篇必须用情绪烈度派——这是和通用 AI 写作工具**最大的审美冲突点**。

## 🏗️ 架构设计

NINGLET 不是"输入大纲 → 输出正文"的黑盒。它是**完整的创作工作台**：作者在每一个环节都有控制权，AI 在底层做脏活累活。

```
┌─────────────────────────────────────────────────────────────────┐
│                        👤 创作者（决策层）                        │
│                                                                │
│  选题材 → 锁情绪 → 排反转 → 写大纲 → 逐节生成 → 去AI味 → 导出   │
│                                                                │
│           每一步都可以介入、修改、推翻                           │
└──────────────────────────────┬──────────────────────────────────┘
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│                    🛠️ NINGLET 工具层                             │
│                                                                │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌───────────┐     │
│  │  🎨 无限画布│ │ 🧭 题材路由 │ │ ⚙️ 逐节配置 │ │ 📋 右键菜单 │     │
│  │   可视化   │ │  字数分流   │ │  情绪烈度  │ │  20+ 操作  │     │
│  └───────────┘ └───────────┘ └───────────┘ └───────────┘     │
│  ┌───────────┐ ┌───────────┐ ┌───────────┐ ┌───────────┐     │
│  │ 🧠 记忆系统 │ │ 🔍 一致性   │ │ 🕵️ AI味检测 │ │ 📤 导出系统 │     │
│  │  分层检索   │ │   五维度   │ │  10项打分  │ │   多格式   │     │
│  └───────────┘ └───────────┘ └───────────┘ └───────────┘     │
└──────────────────────────────┬──────────────────────────────────┘
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│                   🧹 反 AI 味引擎（核心）                        │
│                                                                │
│   禁用词过滤 → 结构规则约束 → 对话规则 → 情绪规则 → 后处理重写   │
└──────────────────────────────┬──────────────────────────────────┘
                               ▼
┌─────────────────────────────────────────────────────────────────┐
│                   🤖 大模型 API 层                               │
│                                                                │
│   DeepSeek · 通义千问 · 豆包 · GPT（任意 OpenAI 兼容接口）       │
└─────────────────────────────────────────────────────────────────┘
```

**三条铁律：**
1. **作者永远是决策者** — AI 是工具不是作者，每个结果都能改、能推翻
2. **控制颗粒度要细** — 不是"写一篇"，而是"这一节用这几个角色、这个节奏、这种情绪"
3. **反馈回路要短** — 写完立刻检测、发现问题立刻重写、不导出到别的工具

## ✍️ 创作流程

短篇流水线，极简为 3 段：

```
 💡 构思          ✍️ 写              🧹 去AI味
   │               │                   │
   │               │                   └─ 禁用词扫描 + 结构检查 + 后处理重写
   │               └─ 注入风格硬约束 + 题材模板 + 短篇格式
   └─ 锁情绪 + 选题材三幕 + 排反转点
```

### 字数路由

| 字数 | 模式 | 说明 |
|:---:|:---:|:---|
| `< 6k` | 单篇流式 | 一次生成全文 |
| `6k – 12k` | 单篇流式 | 甜区下沿，一次生成 |
| `12k – 50k` | 多节预规划 | 全部节拍先规划，再逐节写 |
| `> 50k` | 长篇管道 | 切换长篇模式（rolling window） |

### 支持题材

| 类型 | 细分 |
|:---:|:---|
| 👻 恐怖悬疑 | 规则怪谈 / 民俗 / 无限流 / 细思极恐 |
| 💃 女频 | 甜宠 / 虐恋 / 追妻火葬场 / 重生复仇 |
| 🏃 男频 | 系统流 / 重生 / 扮猪吃虎 |
| 🌿 治愈 | 日常 / 共鸣 / 情感 |
| 💡 脑洞 | 玩梗 / 反转 / 社会热点 |

## 🚀 快速开始

### 环境要求

- **Python** 3.8+
- 任意 **OpenAI 兼容**大模型 API（DeepSeek / 通义千问 / 豆包 / GPT 均可）

### 三步启动

```bash
# 1️⃣ 克隆
git clone git@github.com:XN-289/NINGLET.git
cd NINGLET

# 2️⃣ 安装依赖（仅 3 个，极简）
pip install -r requirements.txt

# 3️⃣ 配置并启动
cp .env.example .env   # 填入你的 API Key
python app.py          # 浏览器打开 http://localhost:20010
```

<details>
<summary><b>📝 .env 配置示例（点击展开）</b></summary>

```env
# 主模型（用于正文生成）
PRIMARY_API_KEY=sk-your-key-here
PRIMARY_API_ENDPOINT=https://api.deepseek.com/v1/chat/completions
PRIMARY_MODEL=deepseek-chat

# 辅助模型（用于 AI 迭代优化，可用低成本模型）
SECONDARY_API_KEY=
SECONDARY_API_ENDPOINT=https://api.deepseek.com/v1/chat/completions
SECONDARY_MODEL=deepseek-chat

# 服务
PORT=20010
HOST=127.0.0.1
```

</details>

> **Windows 用户**：也可以直接双击 `start-short.bat` 一键启动。

## 📁 项目结构

```
NINGLET/
├── app.py                      # Flask 后端（8 个核心路由）
├── modules/
│   ├── shortstory.py           #   短篇引擎：字数路由 + 题材库 + 提示词
│   ├── aidetector.py           #   🕵️ 反 AI 味检测器（10 维度）
│   ├── config.py               #   集中配置 + 禁用词表
│   ├── auth.py                 #   API 鉴权（可选）
│   └── database.py             #   SQLite 持久化（可选）
├── static/                     # 前端：无限画布 + 右键菜单
├── templates/                  # 页面模板
├── docs/
│   └── research/               # 写作方法论调研文档
└── 产出/                       # 创作产出（已脱敏，见下）
```
