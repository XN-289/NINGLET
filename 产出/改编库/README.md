# 改编库（示例占位）

本目录存放"留骨架、换血肉、做去重"的改编作品。

## 目录结构

```
改编库/
├── _改编登记表.md              # 改编进度总表
├── _状态.md                    # 当前状态
└── <原作名>-<改编方向>/
    ├── 改编brief.md            # 改编方向 brief
    ├── 正文.md                 # 改编正文
    ├── 正文-<平台>.md          # 平台定制版（番茄/小红书等）
    └── 质检报告-*.md           # 逐节/全文质检
```

## 说明

- 真实改编内容为商业产出，不公开
- 改编方法论见 `产出/方法论/`
