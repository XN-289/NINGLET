# 拆解文章（示例占位）

本目录存放对优秀短篇作品的"骨架拆解"，用于提炼可复用的写作技法。

## 目录结构（实际使用时）

```
拆解文章/
└── <作者名>/
    ├── _拆解清单.md          # 拆解进度索引
    ├── 001.作品名.md          # 单篇拆解
    │   ├── 原作内核（骨架）
    │   ├── 恐惧/情绪机制
    │   ├── 核心人物关系
    │   ├── 核心物件/场景
    │   ├── 信息差设计
    │   └── 可复用技法提炼
    └── ...
```

## 说明

- 真实拆解内容含版权，不公开，仅本地保存
- 拆解格式见 `产出/方法论/` 下的相关文档
- 本系统支持自动拆解：粘贴原文 → 输出结构化骨架卡
