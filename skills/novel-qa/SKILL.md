# 小说质量审查

## 10 大检查维度

1. **人设一致性** —— 性格是否 OOC、说话风格是否偏离、能力是否无铺垫变化
2. **时间线** —— 事件顺序是否合理、时间跳跃是否有交代
3. **情节逻辑** —— 因果链是否成立、动机是否充分、是否机械降神
4. **对话合理性** —— 是否念稿、信息倾倒、所有角色同语气
5. **伏笔追踪** —— 已埋伏笔是否遗忘、是否该回收未回收
6. **称呼一致** —— 角色称呼/绰号是否漂移
7. **场景/物品一致** —— 前后矛盾（外貌、物品、数字）
8. **情感逻辑** —— 情绪变化是否有过程（不许"想通了"却没过程）
9. **世界观一致** —— 设定是否被违反、力量体系是否崩坏
10. **文风自然度（AI 味）** —— 见下方评分体系

## AI 味评分（0-100）

| 区间 | 判定 |
|---|---|
| 0-20 | 几乎无人味问题 |
| 21-40 | 轻微 |
| 41-60 | 明显 |
| 61-80 | 严重 |
| 81-100 | 全 AI 味 |

**检测指标**：程度副词（不禁/缓缓/淡淡/微微/仿佛/宛如）、情绪描写套话（心中一紧/眼中闪过/嘴角上扬/眉头紧锁）、机械句构、形容词堆砌 3+、机械过渡（然而/于是/因此/与此同时）、套式开头、"Fact ledger" prose（事实流水账）。

**关键区分（不得误判）**：懒人心理总结（"他心想：这件事不简单"）**是** AI 特征；软性内心活动（"我越想越糊涂""我说不上来哪儿不对"）**不是**——这是真人挣扎的表现，不得标记。

## 缺陷分级

- **BLOCKER**：设定/人设/时间线硬冲突，必须修。
- **CRITICAL**：情节逻辑断裂、AI 味严重（评分 ≥61）。
- **MAJOR**：伏笔遗忘、对话念稿、情绪无过程。
- **MINOR**：重复表达、句式单一、轻度 AI 味（评分 41-60）。

## 输出

- 问题清单：编号 + 等级 + 位置（章节/段落）+ 描述 + 建议修法。
- 回归测试：修复后重查，问题状态 OPEN → FIXED / WONT_FIX。

## 报告模板

```
QA 报告 · 第X章
AI 味评分：NN / 100（轻微/明显/严重）
BLOCKER（0 条）：
CRITICAL（N 条）：
  - [C1] 位置 + 描述 + 修法
MAJOR（N 条）：
MINOR（N 条）：
结论：通过 / 需修订
```
